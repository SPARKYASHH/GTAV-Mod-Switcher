# v0.1.2 — GTA V Mod Switcher

## English

Quickly move GTA V mods out of the game directory before GTA Online, then restore your modded Story Mode setup with one button.

### Changes

- Added a dedicated **Simple Trainer** group for `TrainerV.asi` and root-level `trainerv.ini`.
- Preserved the previous Other ASI selection when upgrading an existing profile. Later manual checkbox changes remain respected.
- Added **English | Русский** links to both READMEs and shortened the user instructions.
- Clarified detected mods, Online preparation, storage and startup troubleshooting. Developer details moved into separate documentation.

### Install or update

Download **GTA-V-Mod-Switcher-v0.1.2-Windows.zip** from Assets, extract every file outside GTA, and open **GTA V Mod Switcher.exe**. For an existing installation, close the app and replace its application files. Settings and mod storage remain separate. Optionally run **CREATE-SHORTCUT.cmd** to create or update the desktop shortcut.

Requires Windows 10/11 with built-in Windows PowerShell 5.1 and .NET Framework. The interface is currently in Russian; English instructions explain the controls. [English guide](https://github.com/SPARKYASHH/GTAV-Mod-Switcher/blob/v0.1.2/README.md).

Groups describe files already found in GTA or storage. Simple Trainer configuration kept outside the game directory, such as AppData, stays in place. Check all selected mods, original game files, BattlEye and launcher settings before Online: the switcher does not certify an Online-compatible installation. Legacy was tested on the author's installation; Enhanced paths are recognized but a real Enhanced installation remains unvalidated.

## Русский

Быстро переносите моды GTA V из папки игры перед GTA Online и возвращайте их для сюжетного режима одной кнопкой.

### Что изменилось

- Отдельная группа **Simple Trainer**: `TrainerV.asi` и `trainerv.ini` в корне GTA.
- При обновлении профиля сохраняется прежний выбор из группы «Другие ASI-моды». Последующие изменения галочек не переопределяются.
- Ссылки **English | Русский** в обоих README и более короткая инструкция.
- Понятное описание распознаваемых модов, подготовки к Online, хранилища и ошибок запуска. Сведения для разработчиков перенесены в документацию.

### Установка или обновление

Скачайте **GTA-V-Mod-Switcher-v0.1.2-Windows.zip** из Assets, распакуйте все файлы вне GTA и запустите **GTA V Mod Switcher.exe**. При обновлении закройте программу и замените её файлы. Настройки и хранилище модов остаются отдельно. Для ярлыка при желании запустите **CREATE-SHORTCUT.cmd**. [Русская инструкция](https://github.com/SPARKYASHH/GTAV-Mod-Switcher/blob/v0.1.2/README_RU.md).

Требуются Windows 10/11, встроенные Windows PowerShell 5.1 и .NET Framework. Группы показывают уже найденные файлы. Настройки Simple Trainer вне папки игры, включая AppData, остаются на месте. Перед Online проверьте выбор модов, оригинальные файлы GTA, BattlEye и параметры лаунчера: переключатель не подтверждает полную чистоту игры для Online. Legacy проверена на установке автора; реальная установка Enhanced ещё не проверена.
