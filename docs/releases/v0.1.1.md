## По-русски

Укажите папку GTA V один раз, выберите группы компонентов и отключайте или возвращайте выбранные моды одной кнопкой. Хранилище создаётся автоматически рядом с папкой игры, на том же диске. Файлы не удаляются и не перезаписываются.

**Возможности**

- Минималистичный светлый интерфейс и иконка с V и стрелками.
- Запуск через **GTA V Mod Switcher.exe** без CMD и консоли PowerShell.
- Сохранение пути, групп и отдельных профилей установок.
- Группы Menyoo, Script Hook V, ScriptHookVDotNet, scripts, mods и остальных ASI; графические компоненты предлагаются отдельно.
- Добавление собственных файлов и папок из корня игры.
- Проверка конфликтов, журнал, откат после ошибки и восстановление прерванного переключения.
- При ошибке запуска — отдельное сообщение и локальный журнал.

**Установка**

1. Распакуйте ZIP целиком в постоянную папку **вне GTA и хранилища модов**.
2. Откройте **GTA V Mod Switcher.exe**. Дополнительная установка Python или библиотек не требуется.
3. Выберите папку игры с **GTA5.exe** или вставьте путь и нажмите Enter.
4. Проверьте группы: справа показывается их точный состав. Закройте GTA и переключайте моды основной кнопкой.
5. Для ярлыка с иконкой запустите **CREATE-SHORTCUT.cmd** один раз. Ранее созданный этой программой ярлык обновится.

**Обновление и переход со старого скрипта**

Закройте приложение и распакуйте новую сборку целиком. Настройки и хранилище оконной версии сохраняются отдельно от файлов программы. Если использовали старый консольный **ModSwitch v2** с другим хранилищем, сначала верните моды старым скриптом. Не удаляйте хранилище с отключёнными модами.

## English

Choose your GTA V directory, review component groups, then disable selected mods and restore them with one button. Storage is created automatically beside the game directory on the same drive. The tool does not delete mods or overwrite existing destination files.

**Features**

- Minimal light interface and V / switch-arrow icon.
- **GTA V Mod Switcher.exe** opens without CMD or PowerShell console windows.
- Saved game paths, selected groups and separate installation profiles.
- Menyoo, Script Hook V, ScriptHookVDotNet, scripts, mods and other ASI groups; optional graphics candidates.
- Custom root-level files/folders, conflict checks, journal, rollback and interrupted-operation recovery.
- Startup errors appear in a dialog with a local log path.

**Installation**

1. Extract the complete ZIP to a permanent directory **outside GTA and mod storage**.
2. Open **GTA V Mod Switcher.exe**. No Python or additional library installation is required.
3. Select the game directory containing **GTA5.exe**, or paste its path and press Enter.
4. Review component groups, close GTA, and use the primary button to switch mods.
5. Run **CREATE-SHORTCUT.cmd** once for a desktop shortcut. It updates previous shortcuts created by this utility.

Requires **Windows 10/11** and built-in **Windows PowerShell 5.1 / .NET Framework**. Close the application before updating and keep the package together. Settings and storage are separate from application files. Before migrating from the old console **ModSwitch v2**, restore its mods with the old script first. Never delete storage while it contains disabled mods.

**Validation and scope**

Windows PowerShell 5.1 and PowerShell 7 file-operation tests, WinForms UI, console-free EXE, shortcut and startup failure tests passed. The author confirmed disable/restore, saved settings after restart and console-free startup on their GTA V Legacy installation. Enhanced paths are recognized but real-installation compatibility has not been validated. This remains a preview.

The tool handles selected components; it does not restore modified original game archives, control BattlEye, change launcher options or certify an Online-compatible installation.

See **README.md** in the ZIP and the [GitHub instructions](https://github.com/SPARKYASHH/GTAV-Mod-Switcher/blob/v0.1.1/README.md).
