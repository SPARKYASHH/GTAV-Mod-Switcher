# Проверка перед первым публичным релизом

- Успешные автоматические тесты Windows PowerShell 5.1, PowerShell 7, WinForms.
- Открыть окно через START.cmd из пути с пробелами/кириллицей обычным пользователем.
- Выбрать реальную Legacy, проверить точный состав групп и место хранения.
- Проверить отключение/возврат одного собственного тестового компонента; затем полного набора модов. Сохранения Menyoo должны вернуться без изменений.
- Закрыть и открыть программу: путь, группы и состояние кнопки должны сохраниться.
- Отдельно проверить Enhanced до заявления о полной поддержке.
- При игре, запущенной во время переключения, файлы не должны перемещаться.
- Проверить реальный занятый файл через OpenIV/Проводник, читаемость сообщения и сохранение прежнего состояния.
- Перезапустить после принудительного завершения между двумя перемещениями, проверить восстановление прежнего состояния без потерь.
- Проверить конфликт копий, недоступный родительский каталог и второй экземпляр программы.
- Только после проверки снять отметку preview и подготовить GitHub Release.
